Тестовое задание для AQA стажёра в компании учи.ру

Подготовка к работе
-------------------

Для начала работы убедитесь, что у вас установлены [node.js + npm](https://nodejs.org/en/download)

Установите зависимости проекта, выполнив команду:
```shell
npm ci
```

Запуск тестов
-------------

Запустите тесты с помощью команды:
```shell
npx playwright test
```
## В рамках тестового задания были исправлены существующие автотесты виджета Учи.ру с использованием Playwright и TypeScript

Основные изменения:

- Исправлены некорректные CSS-селекторы элементов виджета

- Устранена ошибка strict mode violation, возникавшая при взаимодействии с элементами

- Сохранена существующая структура тестов с использованием Page Object Model

- Проверено успешное выполнение существующих автотестов
